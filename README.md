# UNCLAIMED / 미수령

야간 택배 배달을 소재로 제작 중인 1인칭 심리 공포게임.

## 개발 환경

- Unity 6000.6.6f1
- Universal Render Pipeline
- Windows PC
- Blender로 제작하는 3D 에셋

## 현재 저장된 작업

- 1인칭 이동과 마우스 시점
- E키 상호작용과 화면 안내
- 택배차 운전석에서 시작하는 자막 오프닝과 하차
- 택배차 뒤에서 상자 꺼내기와 운반
- 배송 정보가 표시된 송장과 F키 송장 확인
- 아파트 입구·계단·6개 층 복도를 잇는 임시 이동 공간
- 송장과 맞는 402호 문 앞에서 E키로 택배 놓기
- 한국어 폰트와 안내 문구

작업 씬: `Assets/_UNCLAIMED/Scenes/Opening_Apartment.unity`

현재 아파트 구조는 기능 확인용 임시 배치이며 최종 외형이나 평면이 아니다.
Unity Play에서 상자 수령·송장 확인·6층까지 이동·문 앞 배치를 확인했다.
사진 촬영과 배송 완료 처리는 아직 구현하지 않았다.

## 다음 제작 방향

- 오프닝은 택배차를 타고 아파트로 가는 도중에 시작한다. 실제 주행 장면과 도시 환경은 추후 제작한다.
- 배달을 마친 뒤 주인공의 집으로 이어지며, 집에서도 사건이 발생하는 방향이다.
- 다음 모델 작업은 아래 참고 이미지 분위기의 낡은 한국 아파트 기본 구조부터 시작한다.
- 문·문틀·손잡이·호수판·인터폰·조명·우편함 등 개별 모델은 품질을 위해 따로 제작하며, 사용자가 제작하자고 지시한 항목만 만든다.
- 참고 이미지에 적힌 시작 위치나 구현 범위는 확정된 게임 설정이 아니다. 이미지의 분위기와 재질을 참고한다.

## 프로젝트 열기

1. Git LFS를 설치한 환경에서 이 저장소를 복제한다.
2. Unity Hub에서 프로젝트 폴더를 추가한다.
3. Unity 6000.6.6f1로 열고 패키지와 에셋 가져오기가 끝날 때까지 기다린다.
4. 작업 씬을 연다.

`Assets`, `.meta` 파일, `Packages`, `ProjectSettings`를 함께 관리한다.
`Library`, `Temp`, `Logs`와 개인 설정은 Unity에서 다시 생성하므로 업로드하지 않는다.
Blender 원본과 FBX 등 큰 바이너리 에셋은 Git LFS로 관리한다.
